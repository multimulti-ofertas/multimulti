Como postar

  1. Toque em Postar no TikTok: a legenda é copiada e o vídeo abre para enviar. Escolha o TikTok.
  2. Se não abrir o TikTok, use Baixar vídeo e depois TikTok → + → Carregar.
  3. No editor: Sons → escolha um som em alta → em Volume, abaixe o som original para 0.
  4. Cole a legenda. Em Mais opções, ligue Divulgação de conteúdo → Conteúdo de marca.
  5. Publicar.
